# Phase 8 Responsive Smoke Notes

Use this checklist for the Phase 8 responsive pass after the app is running
locally.

## Viewports

- Mobile: 390px wide
- Tablet: 768px wide
- Desktop: 1280px wide or wider

## Checks

- Logged-out auth page fills the viewport without horizontal scrolling.
- Dashboard shell fills the viewport without the `html` element scrolling past
  the app.
- Dashboard feed remains usable on desktop and tablet widths.
- Dashboard right column stacks below the feed on smaller widths.
- Post composer buttons wrap cleanly on mobile widths.
- Feed cards, avatars, post footers, and media posts stay within the viewport.
- Text, quote, link, photo, audio, and video post modals fit within mobile and
  tablet viewports.
- Modal content can scroll internally when form content is taller than the
  viewport.
- Recommended users remain readable when stacked below the feed.
